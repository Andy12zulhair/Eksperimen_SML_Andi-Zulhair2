# Eksperimen_SML_Andi-Zulhair
Submission Kriteria 1: Melakukan Eksperimen terhadap Dataset Pelatihan
Nama Siswa: Andi Zulhair

## Struktur Repositori
```text
Eksperimen_SML_Andi-Zulhair/
├── namadataset_raw/
│   └── diabetes_risk_raw.csv
└── preprocessing/
    ├── Eksperimen_Andi-Zulhair.ipynb
    ├── automate_Andi-Zulhair.py
    └── namadataset_preprocessing/
        └── diabetes_risk_clean.csv
```

## Deskripsi Tahapan
1. **namadataset_raw/**: Menyimpan dataset awal mentah (raw data) sebelum diproses.
2. **preprocessing/**:
   - `Eksperimen_Andi-Zulhair.ipynb`: Jupyter Notebook berisi proses Exploratory Data Analysis (EDA), penanganan missing value, feature encoding, dan feature scaling (StandardScaler).
   - `automate_Andi-Zulhair.py`: Skrip otomatisasi pipeline data preprocessing.
   - `namadataset_preprocessing/`: Menyimpan dataset hasil preprocessing yang bersih dan siap untuk pelatihan model machine learning.
